# Glossary

**slug**: Normalised page name. It is the page's folder under the pub folder and the URL path segment.

**pub folder** — the directory (default `~/pub`) holding one sub-folder per published page; mounted into dufs and written by the `pub` CLI.

**publish-html skill** — the agent skill that teaches `pub add`/`ls`/`rm` use from any project; source lives in this repository (`skills/publish-html/`).
